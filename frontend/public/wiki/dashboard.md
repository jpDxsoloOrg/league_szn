# Dashboard

The Dashboard is the first page in the Home section. It shows what's happening in the league at a glance.

## What You'll See

- **Next event** — The top of the page shows the event running now, marked **Live**. If nothing is live, it shows the next event with a countdown and the main event once it's booked. Use **See the card** to open it. If no event has been created yet, it shows the next planned show. Other live and upcoming events are listed underneath.
- **Current Champions** — Active titles with their champions, reign lengths and defenses. Click one to go to the Titles page.
- **Recent Results** — The latest five completed matches. A drawn match shows as a draw. Click a result to open its event, or the Matches tab if it wasn't part of one.
- **Top of the table** — The top five players in the active season. With no active season, or before anyone has wrestled in it, this shows the all-time leaders. Players with no matches aren't listed.
- **My Rivalries** — Up to three of your active rivalries, if you have any.
- **Season Progress** — The active season's name and start date, plus a progress bar when it has an end date.
- **Quick Stats** — Player count, matches this season, matches all time, active titles and the player with the most wins.

## Getting Around

Most panels have a link to the full page, such as **All titles**, **All matches** and **Full standings**. To go anywhere else, use the sections in the main navigation. See [Getting started](getting-started) for what's in each one.
