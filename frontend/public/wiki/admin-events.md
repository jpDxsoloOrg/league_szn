# Managing Events

Events and PPVs are created and run from the **Events** section, not from the Admin panel. The old Match Card Builder is gone: you build the card on the event's own page. Moderators and Admins see the staff controls described here.

## Creating an Event

1. Go to the **Events** section and click **Create Event**
2. Fill in the event details:
   - **Event Type** — PPV, Weekly, Special, or House Show
   - **Event Name** — e.g., "WrestleMania 41", "Monday Night Raw"
   - **Date** — The day the event takes place
   - **Venue** (optional) — e.g., "Madison Square Garden". Leave it blank to pick a saved location at random
   - **Show**, **Company** and **Season** (optional) — Picking a show fills in its name, company and type
   - **Description** (optional) — A description of the event
3. Click **Create Event**. The new event's page opens

## Building a Match Card

Build the card on the event's own page:

1. Open the event from the **Events** section
2. Click **Add Match** to schedule a match straight onto the card
3. Click **Edit** on a match to change it, including its card position (pre-show, opener, midcard, co-main, main event)
4. Use the **Move up** and **Move down** arrows on a match to change the running order
5. Click **Delete** on a match to remove it
6. To put an existing standalone match on a card, edit it under **Standalone Matches** and choose the event

**Add Match** and the arrows appear while the event is upcoming or in progress. Each move saves straight away, and if a save fails the match goes back to where it was. Pre-show matches and main card matches each move within their own section. Moving a match leaves its card position label as it is, so use **Edit** to change that or to bring a match into or out of the pre-show.

**Edit** is only there for matches that haven't been played. Deleting a completed match rolls back its stats.

Championship matches are highlighted with a special badge on the card.

## Running an Event

Staff also get these controls at the top of the event page:

- **Event status** — Upcoming, In Progress, Completed or Cancelled. Recording results moves this along for you: the first result sets In Progress, and the last one sets Completed
- **Edit date and venue** — Change either one
- **Lock sign-ups** — Stops check-ins; **Unlock sign-ups** reopens them
- **Delete** — Removes the event. You can't delete an event that has completed matches. Its unplayed matches stay and become standalone matches

Record results with **Record Result** on each match. See [Record Results](admin-record-results).

## Event Types Explained

| Type | Description |
|------|-------------|
| **PPV** | Major events like WrestleMania, SummerSlam, Royal Rumble |
| **Weekly** | Regular weekly shows like Raw, SmackDown, NXT |
| **Special** | One-off special events, Saturday Night's Main Event, etc. |
| **House Show** | Non-televised events for practice or exhibition |
