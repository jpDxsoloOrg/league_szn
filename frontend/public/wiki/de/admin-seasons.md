# Saisons verwalten

Auf der Seite **Saisons** teilst du die Liga in einzelne Wettbewerbsabschnitte ein.

## Saison erstellen

1. Gehe zu **Saisons** und klicke auf **Neue Saison erstellen**
2. Fülle die Angaben aus:
   - **Saisonname** — z. B. „Saison 1“, „Sommer 2025“
   - **Startdatum** — Wann die Saison beginnt
   - **Enddatum** (optional) — Wann die Saison endet
3. Klicke zum Speichern auf **Saison erstellen**

## Wichtig: Nur eine aktive Saison

Es kann immer nur eine Saison aktiv sein. Du musst die laufende Saison beenden, bevor du eine neue erstellst.

## Saison beenden

1. Suche die aktive Saison im Banner **Aktive Saison**
2. Klicke auf **Saison beenden**
3. Bestätige die Aktion im Dialog
4. Der Status der Saison wechselt zu Abgeschlossen. Hatte sie kein Enddatum, wird das heutige Datum eingetragen

Die Tabelle einer beendeten Saison ist endgültig. Ein geplantes Match, das noch zu ihr gehört, kann erst ein Ergebnis bekommen, wenn du es bearbeitest und eine andere Saison wählst. Die Herausforderer-Ranglisten ruhen, bis eine neue Saison aktiv ist.

## Saison löschen

1. Suche die Saison in der Tabelle **Alle Saisons**
2. Klicke auf **Löschen**
3. Bestätige die Aktion im Dialog

Die aktive Saison kannst du nicht löschen; beende sie zuerst.

**Warnung:** Beim Löschen einer Saison werden auch alle Tabellen und Auszeichnungen dieser Saison endgültig gelöscht. Das kann nicht rückgängig gemacht werden.

## So funktionieren Saisons

- Neue Matches starten mit der aktiven Saison. Wähle **Keine Saison (Showkampf)**, wenn ein Match nicht in die Saisontabelle einfließen soll
- Saisontabellen werden getrennt von der ewigen Tabelle geführt
- Beim Eintragen eines Ergebnisses werden beide Tabellen automatisch aktualisiert
- Abgeschlossene Saisons behalten ihre Bilanzen und lassen sich jederzeit unter **Ranglisten → Tabelle** ansehen
