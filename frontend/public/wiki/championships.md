# Championships Page

View all the championships in the league and their history.

## Viewing Championships

1. Open **Rankings**, then the **Titles** tab.
2. Use the division filter to narrow the list if you want to.
3. Each title shows:
   - Championship name and belt image
   - Tag Team label for tag titles
   - Current champion(s), or **Vacant** if nobody holds it

Inactive titles are listed after the active ones with an **Inactive** badge, so their history stays public.

## Viewing Championship History

1. Click anywhere on a title.
2. A window opens with the history.
3. It lists each champion, the dates won and lost, total days held and defenses. The current reign shows **Current** instead of a lost date.

Reigns by players who have since been removed stay in the history. They show the name on file, or **Former member** if no name can be found.

## Title Matches

The title changes hands when the challenger wins. If the champion wins, it counts as a defense. A draw changes nothing: the champion keeps the title and no defense is added.
