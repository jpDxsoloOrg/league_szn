# Data Management (Danger Zone)

The **Danger Zone** page has tools to generate sample data or completely reset the league. **Full Admin access only** (Moderators can't open it).

**These tools only work on the test site.** On the live league site both are switched off, and trying them shows an error saying the operation is disabled in this environment.

## Generate Sample Data

Quickly populate the test site with sample data for testing or demonstration.

**What Gets Created:**

- **12 Players** — With random win/loss records and assigned wrestlers
- **4 Divisions** — Raw, SmackDown, NXT and Young Boys
- **1 Active Season** — With standings for all players
- **4 Championships** — World, Intercontinental, Tag Team, and US titles
- **12 Matches** — Mix of completed and scheduled matches
- **2 Tournaments** — Single elimination and round robin
- **Events, contender rankings, rivalries, promos and match ratings** — So the rest of the site has something to show

**How to Generate Sample Data:**

1. Open the **Danger Zone** page
2. Click **Generate Sample Data**
3. Confirm the action in the dialog
4. Wait for the data to be created

The **Seed options** checkboxes are not in use yet. You always get the full set, whatever you tick.

**Tip:** For a clean demonstration, use **Clear All Data** first, then generate sample data.

## When to Use Clear All Data

- Resetting the test site
- Cleaning up after a test run

**Extreme Caution:** This action is permanent and irreversible. All data will be lost forever.

## What Gets Deleted

- All players (wrestlers) and their match records
- All matches, results and match ratings
- All championships and their complete history
- All tournaments and brackets
- All seasons, standings and awards
- All divisions
- All events
- All contender rankings and overrides
- All challenges and promos
- All rivalries, with their messages and notes
- All match types and stipulations
- Site settings, including feature switches

User accounts are not deleted.

## How to Clear All Data

1. Open the **Danger Zone** page
2. Read the warning carefully
3. Type the exact phrase **DELETE ALL DATA** in the confirmation box
4. Click **Clear All Data**
5. Confirm the final warning dialog
6. Wait for the process to complete

**Note:** The page has no export button, so there is no way to save a copy or get deleted data back from here.
